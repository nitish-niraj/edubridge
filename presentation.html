Platform Overview

What is EduBridge?

A web-based tutoring marketplace where students discover, book, and attend live 1-on-1 sessions with verified teachers — all within a single browser tab.

Student Portal

Search teachers, book sessions, chat, manage bookings and payments.

Teacher Portal

Set availability, manage sessions, view earnings and student reviews.

Admin Panel

Verify teachers, moderate disputes, push announcements, view analytics.

Live Video

Jitsi Meet SDK embedded directly — no installs, no third-party accounts needed.

Motivation

Problem We Solve

Current Pain Points

  • No unified platform — students find teachers through WhatsApp groups or word-of-mouth
  • No scheduling system — bookings done manually via calls/texts
  • No in-browser video — requires Zoom/Meet installs and separate links
  • No payment transparency — cash-only, no receipts or refund tracking
  • No quality control — unverified teachers, no reviews system

EduBridge Solution

  • Discovery engine — filter teachers by subject, language, price, rating
  • 4-step booking wizard — date → slot → details → payment, all in one flow
  • Embedded Jitsi — live video launches inside the app, no external tools
  • PhonePe gateway — secure digital payments with transaction IDs
  • Admin verification queue — document review + approve/reject workflow

Key Concept: Inertia acts as the glue — no separate REST API for page loads. Async API routes (/api/*) are strictly used for AJAX-style operations like search and chat.

Portal Separation (RBAC)

/student/*role=student

Dashboard, search, booking, chat, profile. Designed mobile-first.

/teacher/*role=teacher

Dashboard, availability, sessions, earnings. Tablet/Desktop optimized.

/admin/*role=admin + 2FA

Users, verification, reports, analytics. Data-dense desktop layouts.
